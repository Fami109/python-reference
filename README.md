# Python 実務リファレンス

実務でPythonを使っていく人向けの文法・Tips リファレンスサイト。
初心者向けサイトには載っていない実践的な知識をまとめています。

## 収録トピック

- 型ヒント完全ガイド (TypeVar, Protocol, TypedDict, Literal)
- dataclass と pydantic の使い分け
- デコレータ実装パターン
- コンテキストマネージャ
- itertools / functools 実務パターン
- collections モジュール
- asyncio 実践
- Walrus演算子 / アンパック応用
- pathlib によるファイル操作
- logging の正しい使い方
- __slots__ / プロファイリング

## 開発

```bash
npm install
npm run dev
```

## デプロイ

```bash
npm run deploy
```
